Essence / mental model

A primary IPv6 address is a globally unique IPv6 address associated with an ENI and marked as its durable primary address; applications can use it when they need the interface identity to remain stable across instance stop and start cycles. EnablePrimaryIpv6 is valid for an ENI in a dual-stack or IPv6-only subnet. AWS chooses the first IPv6 GUA already associated with the interface as primary when the feature is enabled. After primary IPv6 is enabled it cannot be disabled on that ENI. The primary designation persists until the instance is terminated or the network interface is detached, so enabling it is a lifecycle decision rather than a reversible tuning knob. Production scenario: symptom, competing hypotheses, and decision

A blue-green rollout enables primary IPv6 on an existing ENI, but the service continues announcing a different secondary IPv6 address and clients lose connectivity after a restart. Competing hypotheses include stale client state, a routing or DNS defect, an identity-policy denial, a security control, and application failure. The decisive root cause is: The pipeline assumed it could select any address as primary and later undo the change; AWS instead selected the first associated GUA, while the service discovery record still referenced a different address. The corrective sequence is: Inventory ENI address order and consumers before enabling the feature, test on a disposable interface, read back isPrimaryIpv6 and publicIpv6DnsName, update discovery and application binding, verify IPv6 forward and return paths, and replace the ENI instead of attempting an unsupported disable.
