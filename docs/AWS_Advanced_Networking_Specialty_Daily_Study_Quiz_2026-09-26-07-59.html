Decision checkpoints

  • Security groups for Pods use the VPC resource controller and VPC CNI to attach branch ENIs through a node trunk ENI and apply EC2 security groups to selected Pods.
  • A SecurityGroupPolicy selects Pods or service accounts, but scheduling still depends on compatible instance types, branch-ENI capacity, controller readiness, and subnet addresses.
  • Strict and standard enforcement modes change which group and SNAT behavior applies on paths outside the VPC, so the same manifest can produce different egress identities and policy results.
  • Security groups for Pods and Kubernetes network policies are layered controls; readiness probes, NodePort or service paths, Fargate behavior, and supported CNI versions must be tested explicitly.
