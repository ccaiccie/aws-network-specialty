Essence / mental model

Network Address Usage is a unit model for resources that consume addresses or networking scale inside a VPC; the aggregate is not the same as the count of assigned IPv4 addresses. VPC NAU and peered NAU are separate quota boundaries, and peered NAU counts the VPC plus intra-Region peered VPCs rather than inter-Region peers. NAU CloudWatch metrics are not enabled by default; the VPC attribute must be enabled before alarms can observe NetworkAddressUsage and NetworkAddressUsagePeered. Exhausting NAU can prevent new EC2 instances, Network Load Balancers, endpoints, Lambda VPC attachments, Transit Gateway attachments, or NAT gateways even when a subnet appears to have free addresses.   • Lambda VpcConfig accepts up to sixteen subnet IDs and five security-group IDs, plus an Ipv6AllowedForDualStack flag for outbound IPv6 through dual-stack subnets.
