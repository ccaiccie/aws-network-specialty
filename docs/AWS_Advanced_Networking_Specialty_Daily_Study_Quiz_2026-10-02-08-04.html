Decision checkpoints

  • Attaching Lambda to a public subnet does not assign the function a public IP or create internet access; IPv4 egress normally uses private subnets whose route tables send traffic through a NAT gateway.
  • Outbound IPv6 is optional and requires Ipv6AllowedForDualStack plus every selected subnet to have both IPv4 and IPv6 CIDR blocks; IPv6-only subnets are not supported for this Lambda mode.
  • Security-group egress, network ACL return rules, DNS, route-table association, NAT or egress-only gateway health, and destination address-family support all contribute to the actual path.
  • The VpcConfigResponse exposes the selected subnets, security groups, VPC, IPv6 flag, and configuration state, so deployment automation should verify the effective response instead of trusting input alone.
