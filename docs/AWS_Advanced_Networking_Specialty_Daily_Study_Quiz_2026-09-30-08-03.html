Essence / mental model

IPv4 and IPv6 routing are independent in a dual-stack VPC: a public subnet needs ::/0 to an internet gateway, while a private subnet needs ::/0 to an egress-only internet gateway for outbound-only IPv6. A NAT gateway does not provide IPv6 translation for this migration path; IPv6-capable private resources use an egress-only internet gateway when they need outbound internet access without unsolicited inbound reachability. Security groups and custom network ACLs require explicit IPv6 coverage; adding an IPv6 CIDR does not translate existing IPv4 CIDR rules into equivalent IPv6 intent. Address assignment, DNS responses, OS listener bindings, dependency allowlists, and observability must be validated separately, so dual stack should be introduced in controlled phases with IPv4 retained as rollback. The advanced design task is to separate control-plane configuration, data-plane behavior, identity authorization, name resolution, and workload state. A configuration object existing in the console proves only that the service accepted it; it does not prove that every consumer, route, resolver, target, or policy has converged. Production scenario: symptom, competing hypotheses, and decision

Security, governance, scale, and failure boundaries

Apply least privilege at identity, resource, endpoint, network, and application layers. Service Connect TLS uses AWS Private CA and ECS-managed certificate provisioning to encrypt traffic between Service Connect services; the configuration also depends on an IAM role and KMS permissions. Use purpose-built automation roles and review wildcard principals, broad CIDRs, and fail-open defaults. Availability is part of security: an over-broad deny, stale association, unreachable callback, or missing return path can create an outage without improving confidentiality. Use staged enforcement, expiring exceptions, and negative tests. At scale, codify configuration, validate it before deployment, observe it afterward, and reconcile drift only after confirming business ownership and intended path.
